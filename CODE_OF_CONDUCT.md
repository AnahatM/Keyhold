# Code of conduct

## The short version

Be decent. Assume good faith. Criticise code, not people.

## Expected behaviour

- Be respectful of differing viewpoints, experience levels and backgrounds.
- Give and accept constructive feedback gracefully. A code review is about the code.
- Take responsibility for mistakes, apologise, and learn from them.
- Prioritise what is best for the people who will use this software to protect their
  passwords.

## Unacceptable behaviour

- Harassment, insults, or personal or political attacks.
- Sexualised language or imagery, or unwelcome sexual attention.
- Publishing others' private information without explicit permission.
- Deliberately submitting code intended to weaken Keyhold's security, or obscuring the
  security impact of a change.
- Anything else a reasonable person would recognise as inappropriate in a professional
  setting.

## Scope

This applies in all project spaces — issues, pull requests, discussions — and when
representing the project publicly.

## Enforcement

Report problems privately to the maintainer through
[GitHub](https://github.com/AnahatM). Reports are handled confidentially. The maintainer
may edit, remove or reject contributions that violate this document, and may ban a
contributor for behaviour they judge inappropriate, threatening or harmful.
